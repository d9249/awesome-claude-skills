## 이 스킬을 사용해야 하는 경우

다음이 필요한 경우 이 스킬을 사용하세요:
- 적절한 구조와 메타데이터를 갖춘 **새로운 Claude 스킬 생성**
- 배포 준비가 된 **스킬 패키지 생성**
- 팀 가시성을 위해 **생성된 스킬을 Slack 채널에서 자동으로 공유**
- 공유 전 **스킬 구조 검증**
- 팀에 **스킬 패키징 및 배포**

다음의 경우에도 이 스킬을 사용하세요:
- **사용자가 스킬을 만들거나 공유하고 싶다고 말하는 경우**

이 스킬은 다음에 이상적입니다:
- 팀 워크플로의 일부로 스킬 생성
- 스킬 생성과 팀 알림이 필요한 내부 도구 구축
- 스킬 개발 파이프라인 자동화
- 팀 알림과 함께 협업적 스킬 생성

## 주요 기능

### 1. 스킬 생성
- SKILL.md가 있는 적절하게 구조화된 스킬 디렉토리 생성
- 표준화된 scripts/, references/, assets/ 디렉토리 생성
- 필수 메타데이터가 있는 YAML frontmatter 자동 생성
- 명명 규칙 적용(하이픈 케이스)

### 2. 스킬 검증
- SKILL.md 형식 및 필수 필드 검증
- 명명 규칙 확인
- 패키징 전 메타데이터 완전성 보장

### 3. 스킬 패키징
- 배포 가능한 zip 파일 생성
- 모든 스킬 에셋 및 문서 포함
- 패키징 전 자동으로 검증 실행

### 4. Rube를 통한 Slack 통합
- 지정된 Slack 채널로 생성된 스킬 정보 자동 전송
- 스킬 메타데이터(이름, 설명, 링크) 공유
- 팀 발견을 위한 스킬 요약 게시
- 스킬 파일에 대한 직접 링크 제공

## 작동 방식

1. **초기화**: 스킬 이름과 설명 제공
2. **생성**: 적절한 구조로 스킬 디렉토리 생성
3. **검증**: 정확성을 위한 스킬 메타데이터 검증
4. **패키징**: 배포 가능한 형식으로 스킬 패키징
5. **Slack 알림**: 팀의 Slack 채널에 스킬 세부 정보 게시

## 사용 예시

```
Claude에게 "pdf-analyzer"라는 스킬을 만들어 달라고 요청하면:
1. SKILL.md 템플릿이 있는 /skill-pdf-analyzer/ 생성
2. 구조화된 디렉토리 생성 (scripts/, references/, assets/)
3. 스킬 구조 검증
4. 스킬을 zip 파일로 패키징
5. Slack에 게시: "새 스킬 생성됨: pdf-analyzer - 고급 PDF 분석 및 추출 기능"
```

## Rube와의 통합

이 스킬은 다음을 위해 Rube를 활용합니다:
- **SLACK_SEND_MESSAGE**: 팀 채널에 스킬 정보 게시
- **SLACK_POST_MESSAGE_WITH_BLOCKS**: 풍부하게 형식화된 스킬 메타데이터 공유
- **SLACK_FIND_CHANNELS**: 스킬 공지를 위한 대상 채널 발견

## 요구사항

- Rube를 통한 Slack 워크스페이스 연결
- 스킬 생성 디렉토리에 대한 쓰기 액세스
- 스킬 생성 스크립트를 위한 Python 3.7+
- 스킬 알림을 위한 대상 Slack 채널
