# 추첨 당첨자 선택기

이 스킬은 경품 행사 및 콘테스트를 위해 목록, 스프레드시트 또는 Google Sheets에서 무작위로 당첨자를 선택합니다.

## 이 스킬을 사용해야 하는 경우

- 소셜 미디어 경품 행사 운영
- 이벤트에서 추첨 당첨자 선택
- 설문조사 또는 테스트 참가자 무작위 선택
- 콘테스트 제출물에서 당첨자 선택
- 제한된 자리 또는 리소스의 공정한 분배
- 무작위 팀 배정

## 이 스킬이 하는 일

1. **무작위 선택**: 암호학적으로 안전한 무작위 선택 사용
2. **다중 소스**: CSV, Excel, Google Sheets 또는 일반 목록과 작동
3. **다중 당첨자**: 한 명 또는 여러 당첨자 선택 가능
4. **중복 방지**: 동일한 사람이 두 번 당첨되지 않도록 보장
5. **투명한 결과**: 선택 과정을 명확하게 표시
6. **당첨자 세부정보**: 당첨자에 대한 모든 관련 정보 표시

## 사용 방법

### Google Sheets에서

```
경품 행사 당첨자를 선택하기 위해 이 Google Sheet에서
무작위 행을 선택해주세요: [시트 URL]
```

### 로컬 파일에서

```
entries.csv에서 무작위 당첨자 3명을 선택해주세요
```

### 목록에서

```
이 목록에서 무작위 당첨자를 선택해주세요:
- Alice (alice@email.com)
- Bob (bob@email.com)
- Carol (carol@email.com)
...
```

### 다중 당첨자

```
contest-entries.xlsx에서 무작위 당첨자 5명을 선택해주세요,
중복이 없도록 확인해주세요
```

**사용자**: "경품 행사 당첨자를 선택하기 위해 이 Google Sheet에서 무작위 행을 선택해주세요."

**출력**:
```
Google Sheet 액세스 중...
총 참가자 수: 247

🎉 당첨자 선정! 🎉

행 #142

다음 작업을 원하시나요:
- 다른 당첨자 선택 (Sarah 제외)?
- 당첨자 세부정보 내보내기?
- 차순위 당첨자 선택?
```

**영감을 받은 사례:** Lenny의 사용 사례 - 그의 구독자 Slack 커뮤니티에서 Sora 2 경품 당첨자 선택

## 기능

### 공정한 선택
- 안전한 난수 생성 사용
- 편향이나 패턴 없음
- 투명한 과정
- 시드를 통한 반복 가능성(검증용)

### 제외
```
이전 당첨자를 제외하고 무작위 당첨자를 선택해주세요:
Alice, Bob, Carol
```

### 가중 선택
```
"entries" 열을 기반으로 가중 확률로 당첨자를 선택해주세요
(1 참가 = 1 티켓)
```

### 차순위 당첨자
```
목록에서 당첨자 1명과 차순위 당첨자 3명을 선택해주세요
```

## 예시 워크플로

### 소셜 미디어 경품

1. Google Form에서 Google Sheets로 참가자 내보내기
2. "[시트 URL]에서 무작위 당첨자를 선택해주세요"
3. 당첨자 세부정보 확인
4. 타임스탬프와 함께 공개 발표

### 이벤트 추첨

1. 참석자 이름과 이메일의 CSV 생성
2. "attendees.csv에서 무작위 당첨자 10명을 선택해주세요"
3. 당첨자 목록 내보내기
4. 당첨자에게 직접 이메일 발송

### 팀 배정

1. 참가자 목록 준비
2. "이 목록을 4개의 동등한 팀으로 무작위 분할해주세요"
3. 배정 검토
4. 팀 명단 공유

## 팁

- **과정 문서화**: 타임스탬프와 방법 저장
- **공개 발표**: 투명성을 위해 선택 세부정보 공유
- **자격 확인**: 당첨자가 콘테스트 규칙을 충족하는지 확인
- **예비 준비**: 당첨자가 부적격일 경우를 대비해 차순위 당첨자 선택
- **결과 내보내기**: 기록용 당첨자 목록 저장
