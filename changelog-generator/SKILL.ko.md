# Changelog Generator

이 스킬은 기술적인 Git 커밋을 고객과 사용자가 실제로 이해하고 감사할 수 있는 세련되고 사용자 친화적인 변경로그로 변환합니다.

## 이 스킬을 사용하는 경우

- 새 버전의 릴리스 노트 준비
- 주간 또는 월간 제품 업데이트 요약 생성
- 고객을 위한 변경 사항 문서화
- 앱 스토어 제출을 위한 변경로그 항목 작성
- 업데이트 알림 생성
- 내부 릴리스 문서 생성
- 공개 변경로그/제품 업데이트 페이지 유지 관리

## 이 스킬이 하는 일

1. **Git 히스토리 스캔**: 특정 기간 또는 버전 간의 커밋 분석
2. **변경 사항 분류**: 커밋을 논리적 카테고리로 그룹화 (기능, 개선, 버그 수정, 주요 변경 사항, 보안)
3. **기술적 → 사용자 친화적 번역**: 개발자 커밋을 고객 언어로 변환
4. **전문적 포맷팅**: 깔끔하고 구조화된 변경로그 항목 생성
5. **노이즈 필터링**: 내부 커밋(리팩토링, 테스트 등) 제외
6. **모범 사례 준수**: 변경로그 가이드라인 및 브랜드 보이스 적용

## 사용 방법

### 기본 사용법

프로젝트 저장소에서:

```
마지막 릴리스 이후 커밋으로부터 변경로그 생성
```

```
지난 주의 모든 커밋으로 변경로그 생성
```

```
버전 2.5.0의 릴리스 노트 생성
```

### 특정 날짜 범위 사용

```
3월 1일부터 3월 15일까지의 모든 커밋에 대한 변경로그 생성
```

### 사용자 정의 가이드라인 사용

```
v2.4.0 이후 커밋에 대한 변경로그 생성,
CHANGELOG_STYLE.md의 변경로그 가이드라인 사용
```

## 예시

**사용자**: "지난 7일간의 커밋에 대한 변경로그 생성"

**출력**:
```markdown
# 업데이트 - 2024년 3월 10일 주

## ✨ 새로운 기능

- **팀 워크스페이스**: 다양한 프로젝트를 위한 별도의 워크스페이스를 생성합니다.
  팀 멤버를 초대하고 모든 것을 정리된 상태로 유지하세요.

- **키보드 단축키**: ?를 눌러 사용 가능한 모든 단축키를 확인하세요.
  마우스를 사용하지 않고 더 빠르게 탐색하세요.

## 🔧 개선 사항

- **더 빠른 동기화**: 파일이 이제 장치 간에 2배 더 빠르게 동기화됩니다
- **더 나은 검색**: 검색에 이제 제목뿐만 아니라 파일 내용도 포함됩니다

## 🐛 수정 사항

- 큰 이미지가 업로드되지 않는 문제 수정
- 예약된 게시물의 시간대 혼란 해결
- 알림 배지 카운트 수정
```

**영감을 받은 곳:** Lenny's Newsletter의 Manik Aggarwal 사용 사례

## 팁

- Git 저장소 루트에서 실행
- 집중된 변경로그를 위해 날짜 범위 지정
- 일관된 포맷팅을 위해 CHANGELOG_STYLE.md 사용
- 게시하기 전에 생성된 변경로그를 검토하고 조정
- 출력을 CHANGELOG.md에 직접 저장

## 관련 사용 사례

- GitHub 릴리스 노트 생성
- 앱 스토어 업데이트 설명 작성
- 사용자를 위한 이메일 업데이트 생성
- 소셜 미디어 공지 게시물 생성
