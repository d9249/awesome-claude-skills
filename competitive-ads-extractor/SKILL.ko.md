# Competitive Ads Extractor

이 스킬은 광고 라이브러리에서 경쟁사의 광고를 추출하고 무엇이 효과적인지—강조하는 문제, 타겟팅하는 사용 사례, 공감을 얻는 카피/크리에이티브를 분석합니다.

## 이 스킬을 사용하는 경우

- 경쟁사 광고 전략 조사
- 자신의 광고를 위한 영감 찾기
- 시장 포지셔닝 이해
- 성공적인 광고 패턴 식별
- 효과적인 메시징 분석
- 새로운 사용 사례 또는 고충 지점 발견
- 검증된 개념으로 광고 캠페인 계획

## 이 스킬이 하는 일

1. **광고 추출**: Facebook Ad Library, LinkedIn 등에서 광고 스크래핑
2. **스크린샷 캡처**: 모든 광고의 시각적 사본 저장
3. **메시징 분석**: 문제, 사용 사례 및 가치 제안 식별
4. **광고 분류**: 주제, 대상 또는 형식별로 그룹화
5. **패턴 식별**: 공통적인 성공적 접근 방식 찾기
6. **인사이트 제공**: 특정 광고가 잘 수행되는 이유 설명

## 사용 방법

### 기본 추출

```
Facebook Ad Library에서 [경쟁사 이름]의 현재 모든 광고 추출
```

```
[회사]의 광고를 스크래핑하고 메시징 분석
```

### 특정 분석

```
[경쟁사]의 [특정 문제]에 대한 메시징에 초점을 맞춘 모든 광고 가져오기.
그들이 강조하는 고충 지점은 무엇인가요?
```

### 경쟁 세트

```
이 5개 경쟁사의 광고 추출: [목록].
그들의 접근 방식을 비교하고 무엇이 효과적인지 알려주세요.
```

### 특정 플랫폼

```
[경쟁사]의 LinkedIn 광고를 가져와서 B2B 포지셔닝 전략 분석
```

## 예시

**사용자**: "Facebook Ad Library에서 Notion의 광고를 추출하고 그들에게 효과적인 메시징이 무엇인지 알려주세요."

**프로세스**:
```
Facebook Ad Library 접속 중...
검색 중: Notion
발견: 23개의 활성 광고

스크린샷 추출 중...
[████████████████████] 100%

저장 위치: competitor-ads/notion/
- ad-001-collaboration.png
- ad-002-productivity.png
- ad-003-templates.png
...

메시징 분석 중...
```

**출력**:
```
# Notion 광고 분석

## 개요
- 총 광고: 23개 활성
- 주요 테마: 생산성 (35%), 협업 (30%),
  템플릿 (20%), AI 기능 (15%)
- 광고 형식: 정적 이미지 (60%), 비디오 (40%)
- CTA 패턴: "무료로 시도", "시작하기"

## 그들이 강조하는 주요 문제

1. **분산된 정보** (8개 광고)
   카피: "10개의 다른 도구 간 전환 중단"
   효과적인 이유: 많은 팀이 직면한 직접적인 고충 지점

2. **회의 과부하** (5개 광고)
   카피: "불필요한 회의를 비동기 업데이트로 대체"
   효과적인 이유: 코로나 이후 원격 근무 고충 지점

3. **손실된 문서** (4개 광고)
   카피: "다시는 '그 문서가 어디 있지?'라고 묻지 마세요"
   효과적인 이유: 보편적인 직장 불만

## 성공적인 크리에이티브 패턴

### 패턴 1: 전후 분할
- 혼란스러운 도구 환경 → 깔끔한 Notion 작업 공간 표시
- 높은 성과를 보이는 6개 광고에서 사용
- 시각적 은유가 즉시 명확함

### 패턴 2: 기능 쇼케이스
- 실제 제품 사용의 GIF
- 5초 안에 특정 기능 표시
- 새로운 기능(AI, 템플릿)에 사용

### 패턴 3: 사회적 증거
- "2천만 사용자와 함께하세요" 메시징
- 고객 로고
- 엔터프라이즈를 타겟팅하는 4개 광고에서 사용

## 효과적인 카피

최고의 헤드라인:
1. "팀의 지식, 마침내 한 곳에"
   → 이점 중심, 고충을 직접적으로 해결

2. "올인원 작업 공간"
   → 명확한 포지셔닝, 폭넓은 호소력

3. "실제로 작업에 도움이 되는 AI"
   → AI 회의론 해소, 실용적 각도

최고의 본문 카피 패턴:
- 짧은 문장 (10단어 미만)
- 기능이 아닌 결과에 초점
- 구체적인 숫자 포함 ("회의 50% 감소")

## 대상 타겟팅 인사이트

광고 변형을 기반으로:
- 스타트업 창업자: 개인 생산성 각도
- 팀 리더: 협업 및 정렬
- 엔터프라이즈: 보안 및 규정 준수 언급
- 학생: 무료 플랜, 템플릿, 조직

## 광고 권장 사항

1. **"도구 분산" 고충 지점 테스트**
   → 광고 빈도를 기반으로 한 강한 공감대

2. **추상적 비주얼보다 제품 스크린샷 사용**
   → 모든 상위 광고가 실제 UI 표시

3. **솔루션이 아닌 문제로 시작**
   → "X에 지쳤나요?"가 "Y 소개"보다 성과가 좋음

4. **카피를 100자 미만으로 유지**
   → 가장 짧은 광고가 가장 빈번하게 나타남

5. **전후 비주얼 형식 테스트**
   → 크리에이티브에서 검증된 패턴

## 저장된 파일
- 모든 광고: ~/competitor-ads/notion/
- 분석: ~/competitor-ads/notion/analysis.md
- 최고 성과: ~/competitor-ads/notion/top-10/
```

### 캠페인 전략

## 모범 사례

### 법적 및 윤리적

✓ 광고를 직접 복사하지 마세요
✓ 지적 재산권 존중
✓ 인사이트를 사용하여 독창적인 크리에이티브에 정보 제공

### 분석 팁
1. **패턴 찾기**: 어떤 테마가 반복되는가?
2. **시간에 따라 추적**: 월별로 광고를 저장하여 진화 확인
3. **가설 테스트**: 브랜드에 맞게 성공적인 패턴 조정
4. **대상별 세분화**: 다른 타겟에 다른 메시지
5. **플랫폼 비교**: LinkedIn 대 Facebook 메시징이 다름

## 고급 기능

### 트렌드 추적
```
[경쟁사]의 1분기 대 2분기 광고 비교.
어떤 메시징이 변경되었나요?
```

### 다중 경쟁사 분석
```
[회사 A], [회사 B], [회사 C]의 광고 추출.
공통 패턴은 무엇인가요? 어디에서 다른가요?
```

### 산업 벤치마크
```
상위 10개 프로젝트 관리 도구의 광고 패턴 표시.
그들 모두가 어떤 문제에 초점을 맞추나요?
```

### 형식 분석
```
[경쟁사]의 비디오 광고 대 정적 이미지 광고 분석.
어느 것이 더 많은 참여를 얻나요? (데이터가 있는 경우)
```

## 일반적인 워크플로우

### 광고 캠페인 계획
1. 경쟁사 광고 추출
2. 성공적인 패턴 식별
3. 메시징의 격차 주목
4. 독특한 각도 브레인스토밍
5. 테스트 광고 변형 초안 작성

### 포지셔닝 조사
1. 5개 경쟁사의 광고 가져오기
2. 그들의 포지셔닝 매핑
3. 미개척 각도 찾기
4. 차별화된 메시징 개발
5. 그들의 접근 방식에 대해 테스트

### 크리에이티브 영감
1. 테마별로 광고 추출
2. 시각적 패턴 분석
3. 색상 및 레이아웃 트렌드 주목
4. 성공적인 패턴 조정
5. 독창적인 변형 생성

## 성공을 위한 팁

1. **정기적인 모니터링**: 변경 사항을 위해 월별로 확인
2. **광범위한 조사**: 인접한 경쟁사도 확인
3. **모든 것 저장**: 참조 라이브러리 구축
4. **인사이트 테스트**: 자체 실험 실행
5. **성과 추적**: 영감을 받은 개념 A/B 테스트
6. **독창성 유지**: 복사가 아닌 영감을 위해 사용
7. **다중 플랫폼**: Facebook, LinkedIn, TikTok 등 비교

## 출력 형식

- **스크린샷**: 모든 광고가 이미지로 저장됨
- **분석 보고서**: 인사이트의 마크다운 요약
- **스프레드시트**: 광고 카피, CTA, 테마가 있는 CSV
- **프레젠테이션**: 최고 성과의 시각적 덱
- **패턴 라이브러리**: 접근 방식별로 분류

- 제품의 새로운 사용 사례 발견
- 제품 마케팅 전략 계획
- 소셜 미디어 콘텐츠에 영감 주기
