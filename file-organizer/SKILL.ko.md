# 파일 정리자

이 스킬은 개인 정리 도우미로 작동하여 지속적인 수동 정리에 대한 정신적 부담 없이 컴퓨터 전체에 깔끔하고 논리적인 파일 구조를 유지하도록 도와줍니다.

## 이 스킬을 사용해야 할 때

- 다운로드 폴더가 혼란스럽고 지저분함
- 파일이 여기저기 흩어져 있어서 찾을 수 없음
- 공간을 차지하는 중복 파일이 있음
- 폴더 구조가 더 이상 의미가 없음
- 더 나은 정리 습관을 확립하고 싶음
- 새 프로젝트를 시작하고 좋은 구조가 필요함
- 오래된 프로젝트를 보관하기 전에 정리

## 이 스킬이 하는 일

1. **현재 구조 분석**: 폴더와 파일을 검토하여 가지고 있는 것을 이해
2. **중복 찾기**: 시스템 전체에서 중복 파일 식별
3. **정리 제안**: 콘텐츠를 기반으로 논리적인 폴더 구조 제안
4. **정리 자동화**: 승인을 받아 파일을 이동, 이름 변경 및 정리
5. **컨텍스트 유지**: 파일 유형, 날짜 및 콘텐츠를 기반으로 스마트한 결정
6. **잡동사니 줄이기**: 더 이상 필요하지 않을 수 있는 오래된 파일 식별

## 지침

사용자가 파일 정리 도움을 요청할 때:

1. **범위 이해**

   명확한 질문:
   - 어떤 디렉토리를 정리해야 합니까? (다운로드, 문서, 전체 홈 폴더?)
   - 주요 문제는 무엇입니까? (찾을 수 없음, 중복, 너무 지저분함, 구조 없음?)
   - 피해야 할 파일이나 폴더가 있습니까? (현재 프로젝트, 민감한 데이터?)
   - 얼마나 적극적으로 정리합니까? (보수적 대 포괄적 정리)

2. **현재 상태 분석**

   대상 디렉토리 검토:
   ```bash
   # 현재 구조 개요 얻기
   ls -la [target_directory]

   # 파일 유형과 크기 확인
   find [target_directory] -type f -exec file {} \; | head -20

   # 가장 큰 파일 식별
   du -sh [target_directory]/* | sort -rh | head -20

   # 파일 유형 개수 세기
   find [target_directory] -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn
   ```

   발견 사항 요약:
   - 총 파일 및 폴더 수
   - 파일 유형 분석
   - 크기 분포
   - 날짜 범위
   - 명백한 정리 문제

3. **정리 패턴 식별**

   파일을 기반으로 논리적 그룹화 결정:

   **유형별**:
   - 문서(PDF, DOCX, TXT)
   - 이미지(JPG, PNG, SVG)
   - 비디오(MP4, MOV)
   - 압축 파일(ZIP, TAR, DMG)
   - 코드/프로젝트(코드가 있는 디렉토리)
   - 스프레드시트(XLSX, CSV)
   - 프레젠테이션(PPTX, KEY)

   **목적별**:
   - 업무 대 개인
   - 활성 대 보관
   - 프로젝트별
   - 참고 자료
   - 임시/스크래치 파일

   **날짜별**:
   - 현재 연도/월
   - 이전 연도
   - 매우 오래됨(보관 후보)

4. **중복 찾기**

   요청 시 중복 검색:
   ```bash
   # 해시로 정확한 중복 찾기
   find [directory] -type f -exec md5 {} \; | sort | uniq -d

   # 같은 이름을 가진 파일 찾기
   find [directory] -type f -printf '%f\n' | sort | uniq -d

   # 유사한 크기의 파일 찾기
   find [directory] -type f -printf '%s %p\n' | sort -n
   ```

   각 중복 세트에 대해:
   - 모든 파일 경로 표시
   - 크기와 수정 날짜 표시
   - 보관할 것 권장(일반적으로 최신 또는 가장 잘 명명된 것)
   - **중요**: 삭제하기 전에 항상 확인 요청

5. **정리 계획 제안**

   변경하기 전에 명확한 계획 제시:

   ```markdown
   # [디렉토리] 정리 계획

   ## 현재 상태
   - Y개 폴더에 걸쳐 X개 파일
   - 총 [크기]
   - 파일 유형: [분석]
   - 문제: [문제 나열]

   ## 제안된 구조

   ```
   [Directory]/
   ├── Work/
   │   ├── Projects/
   │   ├── Documents/
   │   └── Archive/
   ├── Personal/
   │   ├── Photos/
   │   ├── Documents/
   │   └── Media/
   └── Downloads/
       ├── To-Sort/
       └── Archive/
   ```

   ## 수행할 변경 사항

   1. **새 폴더 만들기**: [나열]
   2. **파일 이동**:
      - X개 PDF → Work/Documents/
      - Y개 이미지 → Personal/Photos/
      - Z개 오래된 파일 → Archive/
   3. **파일 이름 변경**: [이름 변경 패턴]
   4. **삭제**: [중복 또는 쓰레기 파일]

   ## 결정이 필요한 파일

   - [확실하지 않은 파일 나열]

   진행할까요? (예/아니오/수정)
   ```

6. **정리 실행**

   승인 후 체계적으로 정리:

   ```bash
   # 폴더 구조 만들기
   mkdir -p "path/to/new/folders"

   # 명확한 로깅으로 파일 이동
   mv "old/path/file.pdf" "new/path/file.pdf"

   # 일관된 패턴으로 파일 이름 변경
   # 예: "YYYY-MM-DD - Description.ext"
   ```

   **중요 규칙**:
   - 삭제하기 전에 항상 확인
   - 잠재적 실행 취소를 위해 모든 이동 로깅
   - 원래 수정 날짜 보존
   - 파일 이름 충돌을 우아하게 처리
   - 예상치 못한 상황이 발생하면 중지하고 질문

7. **요약 및 유지 관리 팁 제공**

   정리 후:

   ```markdown
   # 정리 완료! ✨

   ## 변경 사항

   - [X]개 새 폴더 생성
   - [Y]개 파일 정리
   - 중복 제거로 [Z] GB 확보
   - [W]개 오래된 파일 보관

   ## 새로운 구조

   [새 폴더 트리 표시]

   ## 유지 관리 팁

   이것을 정리된 상태로 유지하려면:

   1. **주간**: 새 다운로드 정리
   2. **월간**: 완료된 프로젝트 검토 및 보관
   3. **분기별**: 새 중복 확인
   4. **연간**: 오래된 파일 보관

   ## 빠른 명령어

   ```bash
   # 이번 주에 수정된 파일 찾기
   find . -type f -mtime -7

   # 유형별로 다운로드 정리
   [설정에 대한 사용자 정의 명령]

   # 중복 찾기
   [사용자 정의 명령]
   ```

   다른 폴더를 정리하시겠습니까?
   ```

## 예시

### 예시 1: 다운로드 정리(Justin Dielmann에서)

**사용자**: "다운로드 폴더가 500개 이상의 파일로 엉망입니다. 정리하는 데 도움을 주세요."

**프로세스**:
1. 다운로드 폴더 분석
2. 패턴 찾기: 업무 문서, 개인 사진, 설치 프로그램, 무작위 PDF
3. 구조 제안:
   - Downloads/
     - Work/
     - Personal/
     - Installers/(DMG, PKG 파일)
     - Archive/
     - ToSort/(결정이 필요한 것들)
4. 확인 요청
5. 콘텐츠와 이름을 기반으로 파일을 지능적으로 이동
6. 결과: 500개 파일 → 5개 정리된 폴더

### 예시 2: 중복 찾기 및 제거

**사용자**: "Documents에서 중복 파일을 찾고 어느 것을 보관할지 결정하는 데 도움을 주세요."

- `/Documents/old/proposal.pdf` (2.3 MB, 수정일: 2024-03-15)
- `/Desktop/proposal.pdf` (2.3 MB, 수정일: 2024-03-10)

**권장 사항**: `/Documents/proposal.pdf` 보관(올바른 위치에서 가장 최신)

[모든 중복에 대해 계속...]
```

## 전문가 팁

1. **작게 시작**: 신뢰를 구축하기 위해 하나의 지저분한 폴더(다운로드 같은)로 시작
2. **정기적인 유지 관리**: 다운로드에서 주간 정리 실행
3. **일관된 명명**: 중요한 파일에 "YYYY-MM-DD - Description" 형식 사용
4. **적극적으로 보관**: 삭제 대신 오래된 프로젝트를 Archive로 이동
5. **활성과 분리 유지**: 활성 작업과 보관된 작업 사이의 명확한 경계 유지
6. **프로세스 신뢰**: Claude가 어디로 가야 하는지에 대한 인지 부하를 처리하도록 함

## 모범 사례

### 폴더 이름 지정
- 명확하고 설명적인 이름 사용
- 공백 피하기(하이픈 또는 밑줄 사용)
- 구체적으로: "docs"가 아닌 "client-proposals"
- 정렬을 위한 접두사 사용: "01-current", "02-archive"

### 파일 이름 지정
- 날짜 포함: "2024-10-17-meeting-notes.md"
- 설명적으로: "q3-financial-report.xlsx"
- 이름에 버전 번호 피하기(대신 버전 관리 사용)
- 다운로드 아티팩트 제거: "document-final-v2 (1).pdf" → "document.pdf"

### 보관 시기
- 6개월 이상 건드리지 않은 프로젝트
- 나중에 참조할 수 있는 완료된 작업
- 새 시스템으로 마이그레이션한 후 오래된 버전
- 삭제하기 주저되는 파일(먼저 보관)

## 관련 사용 사례

- 새 컴퓨터를 위한 정리 설정
- 백업/보관을 위한 파일 준비
- 저장소 정리 전 정리
- 공유 팀 폴더 정리
- 새 프로젝트 디렉토리 구조화
