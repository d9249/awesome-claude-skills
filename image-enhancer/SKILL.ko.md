# 이미지 향상기

이 스킬은 이미지와 스크린샷을 더 선명하고, 명확하며, 전문적으로 보이도록 개선합니다.

## 이 스킬을 사용해야 할 때

- 블로그 게시물이나 문서를 위한 스크린샷 품질 향상
- 소셜 미디어에서 공유하기 전에 이미지 향상
- 프레젠테이션이나 보고서를 위한 이미지 준비
- 저해상도 이미지 업스케일링
- 흐릿한 사진 선명하게 만들기
- 압축된 이미지 정리

## 이 스킬이 하는 일

1. **이미지 품질 분석**: 해상도, 선명도 및 압축 아티팩트 확인
2. **해상도 향상**: 이미지를 지능적으로 업스케일
3. **선명도 개선**: 가장자리와 세부 사항 향상
4. **아티팩트 감소**: 압축 아티팩트와 노이즈 정리
5. **사용 사례에 맞게 최적화**: 의도한 용도(웹, 인쇄, 소셜 미디어)에 따라 조정

## 사용 방법

### 기본 향상

```
screenshot.png의 이미지 품질을 향상시켜주세요
```

```
이 폴더의 모든 이미지를 향상시켜주세요
```

### 구체적인 개선

```
이 이미지를 4K 해상도로 업스케일해주세요
```

```
이 흐릿한 스크린샷을 선명하게 만들어주세요
```

```
이 이미지의 압축 아티팩트를 줄여주세요
```

### 일괄 처리

```
이 디렉토리의 모든 PNG 파일의 품질을 향상시켜주세요
```

## 예시

**사용자**: "screenshot-2024.png의 이미지 품질을 향상시켜주세요"

**출력**:
```
screenshot-2024.png 분석 중...

현재 사양:
- 해상도: 1920x1080
- 형식: PNG
- 품질: 양호하지만 약간 흐림

적용된 향상:
✓ 2560x1440(레티나)로 업스케일
✓ 가장자리 선명화
✓ 텍스트 명료도 향상
✓ 파일 크기 최적화

다음으로 저장됨: screenshot-2024-enhanced.png
원본 보존: screenshot-2024-original.png
```

**영감을 받은 출처:** Lenny Rachitsky의 뉴스레터 워크플로우 - 기사의 스크린샷에 사용

## 팁

- 항상 원본 파일을 백업으로 유지
- 스크린샷과 디지털 이미지에 가장 잘 작동
- 전체 폴더를 일괄 처리 가능
- 필요한 경우 출력 형식 지정(품질을 위해 PNG, 작은 크기를 위해 JPG)
- 소셜 미디어의 경우 최적의 크기 조정을 위해 플랫폼 언급

## 일반적인 사용 사례

- **블로그 게시물**: 게시하기 전에 스크린샷 향상
- **문서**: UI 스크린샷을 매우 명확하게 만들기
- **소셜 미디어**: Twitter, LinkedIn, Instagram을 위한 이미지 최적화
- **프레젠테이션**: 대형 화면을 위한 이미지 업스케일
- **인쇄 자료**: 물리적 미디어를 위한 해상도 증가
