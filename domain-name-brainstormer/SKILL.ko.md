# 도메인 이름 브레인스토머

이 스킬은 창의적인 옵션을 생성하고 실제로 등록 가능한 도메인을 확인하여 프로젝트에 완벽한 도메인 이름을 찾도록 도와줍니다.

## 이 스킬을 사용해야 할 때

- 새 프로젝트나 회사 시작
- 제품이나 서비스 출시
- 개인 브랜드나 포트폴리오 사이트 만들기
- 기존 프로젝트 리브랜딩
- 사이드 프로젝트용 도메인 등록
- 첫 번째 선택이 사용 중일 때 사용 가능한 대안 찾기

## 이 스킬이 하는 일

1. **프로젝트 이해**: 무엇을 만들고 있는지, 누구를 위한 것인지 분석
2. **창의적인 이름 생성**: 관련성 있고 기억에 남는 도메인 옵션 생성
3. **사용 가능 여부 확인**: 여러 TLD에서 실제로 사용 가능한 도메인 확인
4. **다양한 확장자**: .com, .io, .dev, .ai, .app 등 제안
5. **대안 제공**: 최우선 선택이 사용 중일 경우 변형 제공
6. **브랜딩 인사이트**: 특정 이름이 잘 작동하는 이유 설명

## 사용 방법

### 기본 브레인스토밍

```
원격 팀을 위한 프로젝트 관리 도구를 만들고 있습니다.
도메인 이름을 제안해주세요.
```

```
개인 금융 앱을 위한 도메인 이름 브레인스토밍을 도와주세요
```

### 구체적인 선호도

```
AI 작문 도우미를 위한 도메인 이름이 필요합니다.
.ai나 .io 확장자로 짧은 이름을 선호합니다.
```

### 키워드 포함

```
디자인 에이전시를 위해 "pixel"이나 "studio"라는 단어를 사용한
도메인 이름을 제안해주세요
```

## 예시

**사용자**: "개발자가 코드 스니펫을 공유할 수 있는 도구를 만들고 있습니다. 창의적인 도메인 이름을 제안해주세요."

**출력**:
```
프로젝트 분석 중...
대상 고객: 개발자
주요 기능: 코드 공유, 스니펫, 협업

🎯 도메인 이름 제안

## 사용 가능(.com)
1. ✓ snippetbox.com - 명확하고 기억하기 쉬우며 사용 가능!
   이유: 제품을 직접적으로 설명하며 기억하기 쉬움

2. ✓ codeclip.com - 짧고 간결함
   이유: 빠른 코드 공유를 암시하며 8자에 불과

3. ✓ devpaste.com - 개발자 중심
   이유: 개발자에게 친숙함(pastebin처럼), 명확한 목적

## 사용 가능(대체 TLD)
4. ✓ snippet.dev - 개발자를 위한 완벽한 확장자
   이유: .dev 확장자가 개발자 도구임을 나타냄

5. ✓ codebox.io - 기술 지향적
   이유: .io는 기술 스타트업에서 인기 있으며 깔끔한 이름

6. ✓ sharecode.app - 설명적
   이유: .app 확장자, 명확하게 행동을 나타냄

## 프리미엄/사용 중(.com)
- codeshare.com (사용 중, 예상 $2,500)
- snippets.com (사용 중, 프리미엄 도메인)
```

## 도메인 이름 지정 팁

### 좋은 도메인을 만드는 것

✓ **짧음**: 15자 미만이 이상적
✓ **기억하기 쉬움**: 회상하고 철자하기 쉬움
✓ **발음 가능**: 대화에서 말할 수 있음
✓ **설명적**: 하는 일을 암시함
✓ **브랜드성**: 눈에 띌 만큼 독특함
✓ **하이픈 없음**: 구두로 공유하기 쉬움

### TLD 가이드

- **.com**: 보편적, 신뢰할 수 있음, 비즈니스에 적합
- **.io**: 기술 스타트업, 개발자 도구
- **.dev**: 개발자 중심 제품
- **.ai**: AI/ML 제품
- **.app**: 모바일 또는 웹 애플리케이션
- **.co**: .com의 대안
- **.xyz**: 현대적, 창의적 프로젝트
- **.design**: 크리에이티브/디자인 에이전시
- **.tech**: 기술 회사

## 고급 기능

### 유사한 변형 확인

```
"codebase"와 유사한 변형의 .com, .io, .dev에서
사용 가능 여부를 확인해주세요
```

### 업계별

```
지속 가능한 패션 브랜드를 위한 도메인 이름을 제안하고
.eco와 .fashion TLD를 확인해주세요
```

### 다국어 옵션

```
언어 학습 앱을 위해 영어와 스페인어로
도메인 이름을 브레인스토밍해주세요
```

### 경쟁사 분석

```
성공적인 프로젝트 관리 도구에서 사용하는 도메인 패턴을 보여주고
유사하게 사용 가능한 것을 제안해주세요
```

## 예시 워크플로우

### 스타트업 출시
1. 스타트업 아이디어 설명
2. TLD 전반에 걸쳐 10-15개 도메인 제안 받기
3. 사용 가능 여부와 가격 검토
4. 최우선 3개 선택
5. 즉시 등록

### 개인 브랜드
1. 이름과 직업 공유
2. 변형 받기(firstname.com, firstnamelastname.dev 등)
3. 소셜 미디어 핸들 사용 가능 여부도 확인
4. 플랫폼 전체에서 일관된 브랜드 등록

### 제품 이름 지정
1. 제품과 대상 시장 설명
2. 창의적이고 브랜드화 가능한 이름 받기
3. 상표 충돌 확인
4. 도메인과 소셜 사용 가능 여부 확인
5. 대상 고객과 이름 테스트

## 성공을 위한 팁

1. **빠르게 행동**: 좋은 도메인은 빨리 사용됨
2. **변형 등록**: 브랜드를 보호하기 위해 .com과 .io를 모두 등록
3. **숫자 피하기**: 구두로 전달하기 어려움
4. **소셜 미디어 확인**: @username도 사용 가능한지 확인
5. **소리 내어 말하기**: 발음하기 쉬운지 테스트
6. **상표 확인**: 법적 충돌이 없는지 확인
7. **장기적으로 생각**: 5년 후에도 의미가 있을까?

## 가격 컨텍스트

도메인을 제안할 때 다음을 명시합니다:
- 표준 도메인: 연간 약 $10-15
- 프리미엄 TLD(.io, .ai): 연간 약 $30-50
- 사용 중인 도메인: 목록에 있는 경우 시장 가격
- 프리미엄 도메인: 수백 달러에서 수천 달러

## 관련 도구

도메인을 선택한 후:
- 로고 디자인 옵션 확인
- 소셜 미디어 핸들 확인
- 상표 사용 가능 여부 조사
- 브랜드 아이덴티티 색상/글꼴 계획
