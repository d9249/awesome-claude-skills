# 비디오 다운로더

이 스킬은 YouTube 및 기타 플랫폼에서 컴퓨터로 직접 비디오를 다운로드합니다.

## 이 스킬을 사용해야 하는 경우

- 오프라인 시청을 위한 YouTube 비디오 다운로드
- 참조용 교육 콘텐츠 저장
- 중요한 비디오 보관
- 편집 또는 재사용을 위한 비디오 파일 가져오기
- 플랫폼에서 자신의 콘텐츠 다운로드
- 컨퍼런스 강연 또는 웨비나 저장

## 이 스킬이 하는 일

1. **비디오 다운로드**: YouTube 및 기타 플랫폼에서 비디오 가져오기
2. **품질 선택**: 해상도 선택 가능 (480p, 720p, 1080p, 4K)
3. **형식 옵션**: 다양한 형식으로 다운로드 (MP4, WebM, 오디오 전용)
4. **일괄 다운로드**: 여러 비디오 또는 재생 목록 다운로드 가능
5. **메타데이터 보존**: 제목, 설명 및 썸네일 저장

## 사용 방법

### 기본 다운로드

```
이 YouTube 비디오를 다운로드해주세요: https://youtube.com/watch?v=...
```

```
이 비디오를 1080p 품질로 다운로드해주세요
```

### 오디오 전용

```
이 YouTube 비디오에서 오디오를 MP3로 다운로드해주세요
```

### 재생 목록 다운로드

```
이 YouTube 재생 목록의 모든 비디오를 다운로드해주세요: [URL]
```

### 일괄 다운로드

```
이 5개의 YouTube 비디오를 다운로드해주세요:
1. [URL]
2. [URL]
...
```

## 예시

**사용자**: "이 YouTube 비디오를 다운로드해주세요: https://youtube.com/watch?v=abc123"

**출력**:
```
YouTube에서 다운로드 중...

✓ 썸네일 저장: how-to-build-products-users-love.jpg

저장 위치: ~/Downloads/
```

**영감을 받은 사례:** Lenny의 뉴스레터 워크플로

## 중요 참고 사항

⚠️ **저작권 및 공정 사용**
- 다운로드 권한이 있는 비디오만 다운로드하세요
- 저작권법과 플랫폼 서비스 약관을 존중하세요
- 개인적, 교육적 또는 공정 사용 목적으로 사용하세요
- 저작권이 있는 콘텐츠를 재배포하지 마세요

## 팁

- 파일 크기가 작아야 하는 경우 품질 지정 (720p 대 1080p)
- 팟캐스트나 음악의 경우 공간 절약을 위해 오디오 전용 사용
- 정리된 상태를 유지하기 위해 전용 폴더에 다운로드
- 느린 연결에서 다운로드하기 전에 파일 크기 확인

## 일반적인 사용 사례

- **교육**: 오프라인 학습을 위한 튜토리얼과 강의 저장
- **연구**: 참조용 비디오 보관
- **콘텐츠 제작**: 플랫폼에서 자신의 콘텐츠 다운로드
- **백업**: 제거되기 전에 중요한 비디오 저장
- **오프라인 시청**: 인터넷 없이 비디오 시청
