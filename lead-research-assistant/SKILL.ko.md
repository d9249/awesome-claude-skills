# 리드 조사 도우미

이 스킬은 제품/서비스를 분석하고, 이상적인 고객 프로필을 이해하고, 실행 가능한 아웃리치 전략을 제공하여 비즈니스에 대한 잠재적 리드를 식별하고 자격을 부여하도록 도와줍니다.

## 이 스킬을 사용해야 할 때

- 제품/서비스에 대한 잠재 고객 또는 클라이언트 찾기
- 파트너십을 위해 연락할 회사 목록 구축
- 영업 아웃리치를 위한 대상 계정 식별
- 이상적인 고객 프로필과 일치하는 회사 조사
- 비즈니스 개발 활동 준비

## 이 스킬이 하는 일

1. **비즈니스 이해**: 제품/서비스, 가치 제안 및 대상 시장 분석
2. **대상 회사 식별**: 이상적인 고객 프로필과 일치하는 회사를 다음을 기반으로 찾기:
   - 업계 및 섹터
   - 회사 규모 및 위치
   - 기술 스택 및 사용하는 도구
   - 성장 단계 및 자금 조달
   - 제품이 해결하는 문제점
3. **리드 우선순위 지정**: 적합성 점수와 관련성에 따라 회사 순위 매기기
4. **연락 전략 제공**: 각 리드에 대해 맞춤화된 메시징으로 접근 방법 제안
5. **데이터 보강**: 의사 결정권자와 회사 컨텍스트에 대한 관련 정보 수집

## 사용 방법

### 기본 사용법

제품/서비스와 찾고 있는 것을 간단히 설명:

```
[제품 설명]을 만들고 있습니다. [위치/업계]에서
이것에 좋은 리드가 될 10개 회사를 찾아주세요.
```

### 코드베이스 사용

더 나은 결과를 위해 제품의 소스 코드 디렉토리에서 실행:

```
이 저장소에서 만들고 있는 것을 보고
[위치/업계]에서 이 제품으로 혜택을 받을 상위 10개 회사를 식별해주세요.
```

### 고급 사용

더 타겟팅된 조사를 위해:

```
내 제품: [설명]
이상적인 고객 프로필:
- 업계: [업계]
- 회사 규모: [크기 범위]
- 위치: [위치]
- 현재 문제점: [문제점]
- 사용하는 기술: [기술 스택]

각각에 대한 연락 전략과 함께 20개의 자격을 갖춘 리드를 찾아주세요.
```

## 지침

사용자가 리드 조사를 요청할 때:

1. **제품/서비스 이해**
   - 코드 디렉토리에 있는 경우 코드베이스를 분석하여 제품 이해
   - 가치 제안에 대한 명확한 질문
   - 주요 기능 및 이점 식별
   - 해결하는 문제 이해

2. **이상적인 고객 프로필 정의**
   - 대상 업계 및 섹터 결정
   - 회사 규모 범위 식별
   - 지리적 선호도 고려
   - 관련 문제점 이해
   - 기술 요구 사항 메모

3. **리드 조사 및 식별**
   - 기준과 일치하는 회사 검색
   - 필요의 신호 찾기(구인 공고, 기술 스택, 최근 뉴스)
   - 성장 지표 고려(자금 조달, 확장, 채용)
   - 보완 제품/서비스가 있는 회사 식별
   - 예산 지표 확인

4. **우선순위 지정 및 점수**
   - 각 리드에 대한 적합성 점수(1-10) 생성
   - 다음과 같은 요소 고려:
     - ICP와의 정렬
     - 즉각적인 필요의 신호
     - 예산 가용성
     - 경쟁 환경
     - 타이밍 지표

5. **실행 가능한 출력 제공**

   각 리드에 대해 제공:
   - **회사 이름** 및 웹사이트
   - **좋은 적합인 이유**: 비즈니스를 기반으로 한 구체적인 이유
   - **우선순위 점수**: 설명과 함께 1-10
   - **의사 결정권자**: 대상 역할/직함(예: "VP of Engineering")
   - **연락 전략**: 맞춤화된 접근 제안
   - **가치 제안**: 제품이 특정 문제를 해결하는 방법
   - **대화 시작점**: 아웃리치에서 언급할 구체적인 요점
   - **LinkedIn URL**: 가능한 경우 쉬운 연결을 위해

6. **출력 형식 지정**

   명확하고 스캔 가능한 형식으로 결과 제시:

   ```markdown
   # 리드 조사 결과

   ## 요약
   - 찾은 총 리드: [X]
   - 높은 우선순위(8-10): [X]
   - 중간 우선순위(5-7): [X]
   - 평균 적합성 점수: [X]

   ---

   ## 리드 1: [회사 이름]

   **웹사이트**: [URL]
   **우선순위 점수**: [X/10]
   **업계**: [업계]
   **크기**: [직원 수/수익 범위]

   **좋은 적합인 이유**:
   [비즈니스를 기반으로 한 2-3가지 구체적인 이유]

   **대상 의사 결정권자**: [역할/직함]
   **LinkedIn**: [가능한 경우 URL]

   **그들을 위한 가치 제안**:
   [이 회사에 대한 구체적인 이점]

   **아웃리치 전략**:
   [맞춤화된 접근 - 구체적인 문제점, 최근 회사 뉴스 또는 관련 컨텍스트 언급]

   **대화 시작점**:
   - [구체적인 요점 1]
   - [구체적인 요점 2]

   ---

   [각 리드에 대해 반복]
   ```

7. **다음 단계 제공**
   - CRM 가져오기를 위해 결과를 CSV로 저장 제안
   - 맞춤화된 아웃리치 메시지 초안 작성 제공
   - 타이밍을 기반으로 우선순위 지정 권장
   - 최고 리드에 대한 후속 조사 제안

## 예시

### 예시 1: Lenny's Newsletter에서

**사용자**: "AI 코딩 도우미 쿼리에서 민감한 데이터를 마스킹하는 도구를 만들고 있습니다. 잠재적 리드를 찾아주세요."

**출력**: 다음과 같은 회사의 우선순위 목록 생성:
- AI 코딩 도우미(Copilot, Cursor 등)를 사용
- 민감한 데이터 처리(핀테크, 의료, 법률)
- GitHub 저장소에서 코딩 에이전트 사용의 증거가 있음
- 코드에서 민감한 데이터를 실수로 노출했을 수 있음
- 관련 의사 결정권자의 LinkedIn URL 포함

### 예시 2: 지역 비즈니스

**사용자**: "원격 팀 생산성을 위한 컨설팅 업무를 운영합니다. 최근 원격으로 전환한 베이 지역의 10개 회사를 찾아주세요."

**출력**: 다음과 같은 회사 식별:
- 최근 원격 구인 공고 게시
- 원격 우선 정책 발표
- 분산 팀 채용
- 원격 작업 문제의 징후 표시
- 각각에 대한 맞춤화된 아웃리치 전략 제공

## 최상의 결과를 위한 팁

- 제품과 고유한 가치에 대해 **구체적으로** 설명
- 해당하는 경우 자동 컨텍스트를 위해 **코드베이스에서 실행**
- 이상적인 고객 프로필에 대한 **컨텍스트 제공**
- 업계, 위치 또는 회사 규모와 같은 **제약 조건 지정**
- 유망한 리드에 대한 더 깊은 인사이트를 위해 **후속 조사 요청**

## 관련 사용 사례

- 리드 식별 후 맞춤화된 아웃리치 이메일 초안 작성
- 자격을 갖춘 잠재 고객의 CRM 준비 CSV 구축
- 특정 회사에 대한 세부 조사
- 경쟁사 고객 기반 분석
- 파트너십 기회 식별
