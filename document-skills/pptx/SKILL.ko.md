# PPTX 생성, 편집 및 분석

## 개요

사용자가 .pptx 파일의 내용을 생성, 편집 또는 분석하도록 요청할 수 있습니다. .pptx 파일은 기본적으로 XML 파일과 기타 리소스를 포함하는 ZIP 아카이브로, 읽거나 편집할 수 있습니다. 다양한 작업에 사용할 수 있는 다양한 도구와 워크플로우가 있습니다.

## 콘텐츠 읽기 및 분석

### 텍스트 추출
프레젠테이션의 텍스트 내용만 읽어야 하는 경우 문서를 마크다운으로 변환해야 합니다:

```bash
# 문서를 마크다운으로 변환
python -m markitdown path-to-file.pptx
```

### 원시 XML 접근
주석, 발표자 노트, 슬라이드 레이아웃, 애니메이션, 디자인 요소 및 복잡한 서식 지정에는 원시 XML 접근이 필요합니다. 이러한 기능을 사용하려면 프레젠테이션의 압축을 풀고 원시 XML 내용을 읽어야 합니다.

#### 파일 압축 해제
`python ooxml/scripts/unpack.py <office_file> <output_dir>`

**참고**: unpack.py 스크립트는 프로젝트 루트를 기준으로 `skills/pptx/ooxml/scripts/unpack.py`에 있습니다. 이 경로에 스크립트가 없는 경우 `find . -name "unpack.py"`를 사용하여 찾으십시오.

#### 주요 파일 구조
* `ppt/presentation.xml` - 주요 프레젠테이션 메타데이터 및 슬라이드 참조
* `ppt/slides/slide{N}.xml` - 개별 슬라이드 내용 (slide1.xml, slide2.xml 등)
* `ppt/notesSlides/notesSlide{N}.xml` - 각 슬라이드의 발표자 노트
* `ppt/comments/modernComment_*.xml` - 특정 슬라이드의 주석
* `ppt/slideLayouts/` - 슬라이드의 레이아웃 템플릿
* `ppt/slideMasters/` - 마스터 슬라이드 템플릿
* `ppt/theme/` - 테마 및 스타일 정보
* `ppt/media/` - 이미지 및 기타 미디어 파일

#### 타이포그래피 및 색상 추출
**예제 디자인을 모방하도록 지시받은 경우**: 항상 아래 방법을 사용하여 프레젠테이션의 타이포그래피와 색상을 먼저 분석하십시오:
1. **테마 파일 읽기**: 색상(`<a:clrScheme>`)과 글꼴(`<a:fontScheme>`)을 확인하기 위해 `ppt/theme/theme1.xml`을 확인합니다
2. **슬라이드 콘텐츠 샘플링**: 실제 글꼴 사용(`<a:rPr>`)과 색상을 위해 `ppt/slides/slide1.xml`을 검사합니다
3. **패턴 검색**: grep을 사용하여 모든 XML 파일에서 색상(`<a:solidFill>`, `<a:srgbClr>`) 및 글꼴 참조를 찾습니다

## **템플릿 없이** 새 PowerPoint 프레젠테이션 만들기

처음부터 새 PowerPoint 프레젠테이션을 만들 때 **html2pptx** 워크플로우를 사용하여 HTML 슬라이드를 정확한 위치 지정으로 PowerPoint로 변환합니다.

### 디자인 원칙

**중요**: 프레젠테이션을 만들기 전에 콘텐츠를 분석하고 적절한 디자인 요소를 선택하십시오:
1. **주제 고려**: 이 프레젠테이션의 주제는 무엇입니까? 어떤 톤, 산업 또는 분위기를 제안합니까?
2. **브랜딩 확인**: 사용자가 회사/조직을 언급하는 경우 브랜드 색상과 정체성을 고려하십시오
3. **콘텐츠에 맞는 팔레트**: 주제를 반영하는 색상을 선택하십시오
4. **접근 방식 명시**: 코드를 작성하기 전에 디자인 선택을 설명하십시오

**요구 사항**:
- ✅ 코드를 작성하기 전에 콘텐츠 기반 디자인 접근 방식을 명시하십시오
- ✅ 웹 안전 글꼴만 사용: Arial, Helvetica, Times New Roman, Georgia, Courier New, Verdana, Tahoma, Trebuchet MS, Impact
- ✅ 크기, 굵기 및 색상을 통해 명확한 시각적 계층 구조를 만드십시오
- ✅ 가독성 보장: 강한 대비, 적절한 크기의 텍스트, 깔끔한 정렬
- ✅ 일관성 유지: 슬라이드 전체에서 패턴, 간격 및 시각적 언어를 반복하십시오

#### 색상 팔레트 선택

**색상을 창의적으로 선택하기**:
- **기본값을 넘어서 생각**: 이 특정 주제에 진정으로 맞는 색상은 무엇입니까? 자동 조종 선택을 피하십시오.
- **여러 각도 고려**: 주제, 산업, 분위기, 에너지 레벨, 대상 고객, 브랜드 정체성(언급된 경우)
- **모험적으로**: 예상치 못한 조합을 시도하십시오 - 의료 프레젠테이션이 녹색일 필요는 없고, 금융이 네이비 블루일 필요도 없습니다

#### 시각적 세부 사항 옵션

**기하학적 패턴**:
- 수평 대신 대각선 섹션 구분선
- 비대칭 열 너비(30/70, 40/60, 25/75)
- 90° 또는 270°로 회전된 텍스트 헤더
- 이미지를 위한 원형/육각형 프레임
- 모서리의 삼각형 강조 모양
- 깊이를 위한 겹치는 모양

**테두리 & 프레임 처리**:
- 한쪽에만 두꺼운 단색 테두리(10-20pt)
- 대조적인 색상의 이중선 테두리
- 전체 프레임 대신 모서리 브래킷
- L자형 테두리(상단+왼쪽 또는 하단+오른쪽)
- 헤더 아래 밑줄 강조(3-5pt 두께)

**타이포그래피 처리**:
- 극단적인 크기 대비(72pt 헤드라인 vs 11pt 본문)
- 넓은 자간을 가진 대문자 헤더
- 초대형 디스플레이 타입의 번호 매긴 섹션
- 데이터/통계/기술 콘텐츠를 위한 고정폭(Courier New)
- 밀집된 정보를 위한 압축 글꼴(Arial Narrow)
- 강조를 위한 윤곽선 텍스트

**차트 & 데이터 스타일링**:
- 주요 데이터를 위한 단일 강조 색상의 단색 차트
- 수직 대신 수평 막대 차트
- 막대 차트 대신 점 플롯
- 최소 격자선 또는 전혀 없음
- 요소에 직접 데이터 레이블(범례 없음)
- 주요 메트릭을 위한 초대형 숫자

**레이아웃 혁신**:
- 텍스트 오버레이가 있는 전체 여백 이미지
- 탐색/컨텍스트를 위한 사이드바 열(20-30% 너비)
- 모듈식 그리드 시스템(3×3, 4×4 블록)
- Z-패턴 또는 F-패턴 콘텐츠 흐름
- 색상 모양 위에 떠 있는 텍스트 상자
- 잡지 스타일 다중 열 레이아웃

**배경 처리**:
- 슬라이드의 40-60%를 차지하는 단색 블록
- 그라디언트 채우기(수직 또는 대각선만)
- 분할 배경(두 가지 색상, 대각선 또는 수직)
- 가장자리에서 가장자리까지 색상 밴드
- 디자인 요소로서의 여백

### 레이아웃 팁
**차트 또는 표가 있는 슬라이드를 만들 때:**
- **2열 레이아웃(권장)**: 전체 너비에 걸친 헤더를 사용한 다음 아래에 두 개의 열 - 한 열에 텍스트/글머리 기호, 다른 열에 주요 콘텐츠. 이것은 더 나은 균형을 제공하고 차트/표를 더 읽기 쉽게 만듭니다. 각 콘텐츠 유형에 대한 공간을 최적화하기 위해 불균등한 열 너비(예: 40%/60% 분할)와 함께 flexbox를 사용하십시오.
- **전체 슬라이드 레이아웃**: 최대 영향과 가독성을 위해 주요 콘텐츠(차트/표)가 전체 슬라이드를 차지하도록 합니다
- **절대 수직으로 쌓지 마십시오**: 단일 열에서 텍스트 아래에 차트/표를 배치하지 마십시오 - 이것은 가독성이 낮고 레이아웃 문제를 일으킵니다

### 워크플로우
1. **필수 - 전체 파일 읽기**: [`html2pptx.md`](html2pptx.md)를 처음부터 끝까지 완전히 읽으십시오. **이 파일을 읽을 때 범위 제한을 설정하지 마십시오.** 프레젠테이션 생성을 진행하기 전에 자세한 구문, 중요한 서식 지정 규칙 및 모범 사례에 대한 전체 파일 내용을 읽으십시오.
2. 적절한 치수로 각 슬라이드에 대한 HTML 파일을 만듭니다(예: 16:9의 경우 720pt × 405pt)
   - 모든 텍스트 콘텐츠에 `<p>`, `<h1>`-`<h6>`, `<ul>`, `<ol>`을 사용하십시오
   - 차트/표가 추가될 영역에 `class="placeholder"`를 사용하십시오(가시성을 위해 회색 배경으로 렌더링)
   - **중요**: Sharp를 사용하여 먼저 그라디언트와 아이콘을 PNG 이미지로 래스터화한 다음 HTML에서 참조하십시오
   - **레이아웃**: 차트/표/이미지가 있는 슬라이드의 경우 더 나은 가독성을 위해 전체 슬라이드 레이아웃 또는 2열 레이아웃을 사용하십시오
3. [`html2pptx.js`](scripts/html2pptx.js) 라이브러리를 사용하여 HTML 슬라이드를 PowerPoint로 변환하고 프레젠테이션을 저장하는 JavaScript 파일을 만들고 실행합니다
   - 각 HTML 파일을 처리하기 위해 `html2pptx()` 함수를 사용하십시오
   - PptxGenJS API를 사용하여 자리 표시자 영역에 차트와 표를 추가하십시오
   - `pptx.writeFile()`을 사용하여 프레젠테이션을 저장하십시오
4. **시각적 검증**: 썸네일을 생성하고 레이아웃 문제를 검사합니다
   - 썸네일 그리드 만들기: `python scripts/thumbnail.py output.pptx workspace/thumbnails --cols 4`
   - 썸네일 이미지를 읽고 다음을 주의 깊게 검사하십시오:
     - **텍스트 잘림**: 헤더 바, 모양 또는 슬라이드 가장자리에 의해 잘린 텍스트
     - **텍스트 겹침**: 다른 텍스트 또는 모양과 겹치는 텍스트
     - **위치 지정 문제**: 슬라이드 경계 또는 다른 요소에 너무 가까운 콘텐츠
     - **대비 문제**: 텍스트와 배경 사이의 대비 부족
   - 문제가 발견되면 HTML 여백/간격/색상을 조정하고 프레젠테이션을 다시 생성하십시오
   - 모든 슬라이드가 시각적으로 올바를 때까지 반복하십시오

## 기존 PowerPoint 프레젠테이션 편집

기존 PowerPoint 프레젠테이션의 슬라이드를 편집할 때 원시 Office Open XML(OOXML) 형식으로 작업해야 합니다. 여기에는 .pptx 파일의 압축을 풀고, XML 내용을 편집하고, 다시 압축하는 작업이 포함됩니다.

### 워크플로우
1. **필수 - 전체 파일 읽기**: [`ooxml.md`](ooxml.md)(~500줄)를 처음부터 끝까지 완전히 읽으십시오. **이 파일을 읽을 때 범위 제한을 설정하지 마십시오.** 프레젠테이션 편집 전에 OOXML 구조 및 편집 워크플로우에 대한 자세한 지침을 위해 전체 파일 내용을 읽으십시오.
2. 프레젠테이션 압축 해제: `python ooxml/scripts/unpack.py <office_file> <output_dir>`
3. XML 파일 편집(주로 `ppt/slides/slide{N}.xml` 및 관련 파일)
4. **중요**: 각 편집 후 즉시 검증하고 계속하기 전에 검증 오류를 수정하십시오: `python ooxml/scripts/validate.py <dir> --original <file>`
5. 최종 프레젠테이션 압축: `python ooxml/scripts/pack.py <input_directory> <office_file>`

## **템플릿을 사용하여** 새 PowerPoint 프레젠테이션 만들기

기존 템플릿의 디자인을 따르는 프레젠테이션을 만들어야 하는 경우 템플릿 슬라이드를 복제하고 재배열한 다음 자리 표시자 컨텍스트를 교체해야 합니다.

### 워크플로우
1. **템플릿 텍스트 추출 및 시각적 썸네일 그리드 만들기**:
   * 텍스트 추출: `python -m markitdown template.pptx > template-content.md`
   * `template-content.md` 읽기: 템플릿 프레젠테이션의 내용을 이해하기 위해 전체 파일을 읽으십시오. **이 파일을 읽을 때 범위 제한을 설정하지 마십시오.**
   * 썸네일 그리드 만들기: `python scripts/thumbnail.py template.pptx`
   * 자세한 내용은 [썸네일 그리드 만들기](#creating-thumbnail-grids) 섹션을 참조하십시오

2. **템플릿 분석 및 인벤토리를 파일에 저장**:
   * **시각적 분석**: 썸네일 그리드를 검토하여 슬라이드 레이아웃, 디자인 패턴 및 시각적 구조를 이해합니다
   * `template-inventory.md`에 템플릿 인벤토리 파일을 만들고 저장합니다:
     ```markdown
     # 템플릿 인벤토리 분석
     **총 슬라이드: [개수]**
     **중요: 슬라이드는 0부터 시작합니다(첫 번째 슬라이드 = 0, 마지막 슬라이드 = 개수-1)**

     ## [카테고리 이름]
     - 슬라이드 0: [레이아웃 코드(사용 가능한 경우)] - 설명/목적
     - 슬라이드 1: [레이아웃 코드] - 설명/목적
     - 슬라이드 2: [레이아웃 코드] - 설명/목적
     [... 모든 슬라이드는 인덱스와 함께 개별적으로 나열되어야 합니다 ...]
     ```
   * **썸네일 그리드 사용**: 시각적 썸네일을 참조하여 다음을 식별합니다:
     - 레이아웃 패턴(제목 슬라이드, 콘텐츠 레이아웃, 섹션 구분선)
     - 이미지 자리 표시자 위치 및 개수
     - 슬라이드 그룹 전체의 디자인 일관성
     - 시각적 계층 구조 및 구조
   * 이 인벤토리 파일은 다음 단계에서 적절한 템플릿을 선택하는 데 필요합니다

3. **템플릿 인벤토리를 기반으로 프레젠테이션 개요 만들기**:
   * 2단계에서 사용 가능한 템플릿을 검토합니다.
   * 첫 번째 슬라이드에 대한 소개 또는 제목 템플릿을 선택합니다. 이것은 첫 번째 템플릿 중 하나여야 합니다.
   * 다른 슬라이드에 대해 안전하고 텍스트 기반 레이아웃을 선택합니다.
   * **중요: 레이아웃 구조를 실제 콘텐츠와 일치시키십시오**:
     - 단일 열 레이아웃: 통일된 서사 또는 단일 주제에 사용
     - 2열 레이아웃: 정확히 2개의 고유한 항목/개념이 있을 때만 사용
     - 3열 레이아웃: 정확히 3개의 고유한 항목/개념이 있을 때만 사용
     - 이미지 + 텍스트 레이아웃: 삽입할 실제 이미지가 있을 때만 사용
     - 인용 레이아웃: 사람의 실제 인용(귀속 포함)에만 사용, 강조용으로 절대 사용하지 마십시오
     - 콘텐츠보다 더 많은 자리 표시자가 있는 레이아웃을 절대 사용하지 마십시오
     - 2개 항목이 있는 경우 3열 레이아웃에 강제로 넣지 마십시오
     - 4개 이상의 항목이 있는 경우 여러 슬라이드로 나누거나 목록 형식을 사용하는 것을 고려하십시오
   * 레이아웃을 선택하기 전에 실제 콘텐츠 부분을 세십시오
   * 선택한 레이아웃의 각 자리 표시자가 의미 있는 콘텐츠로 채워질지 확인하십시오
   * 각 콘텐츠 섹션에 대해 **최상의** 레이아웃을 나타내는 하나의 옵션을 선택하십시오.
   * 사용 가능한 디자인을 활용하는 콘텐츠 및 템플릿 매핑으로 `outline.md`를 저장하십시오
   * 템플릿 매핑 예:
      ```
      # 사용할 템플릿 슬라이드(0부터 시작하는 인덱싱)
      # 경고: 인덱스가 범위 내에 있는지 확인하십시오! 73개 슬라이드가 있는 템플릿은 인덱스 0-72를 가집니다
      # 매핑: 개요의 슬라이드 번호 -> 템플릿 슬라이드 인덱스
      template_mapping = [
          0,   # 슬라이드 0 사용(제목/표지)
          34,  # 슬라이드 34 사용(B1: 제목 및 본문)
          34,  # 슬라이드 34를 다시 사용(두 번째 B1을 위해 복제)
          50,  # 슬라이드 50 사용(E1: 인용)
          54,  # 슬라이드 54 사용(F2: 마무리 + 텍스트)
      ]
      ```

4. **`rearrange.py`를 사용하여 슬라이드 복제, 재정렬 및 삭제**:
   * `scripts/rearrange.py` 스크립트를 사용하여 원하는 순서로 슬라이드가 있는 새 프레젠테이션을 만듭니다:
     ```bash
     python scripts/rearrange.py template.pptx working.pptx 0,34,34,50,52
     ```
   * 스크립트는 반복되는 슬라이드 복제, 사용하지 않는 슬라이드 삭제 및 자동으로 재정렬을 처리합니다
   * 슬라이드 인덱스는 0부터 시작합니다(첫 번째 슬라이드는 0, 두 번째는 1 등)
   * 동일한 슬라이드 인덱스가 여러 번 나타나 해당 슬라이드를 복제할 수 있습니다

5. **`inventory.py` 스크립트를 사용하여 모든 텍스트 추출**:
   * **인벤토리 추출 실행**:
     ```bash
     python scripts/inventory.py working.pptx text-inventory.json
     ```
   * **text-inventory.json 읽기**: 모든 모양과 속성을 이해하기 위해 전체 text-inventory.json 파일을 읽으십시오. **이 파일을 읽을 때 범위 제한을 설정하지 마십시오.**

   * 인벤토리 JSON 구조:
      ```json
        {
          "slide-0": {
            "shape-0": {
              "placeholder_type": "TITLE",  // 또는 자리 표시자가 아닌 경우 null
              "left": 1.5,                  // 인치 단위 위치
              "top": 2.0,
              "width": 7.5,
              "height": 1.2,
              "paragraphs": [
                {
                  "text": "단락 텍스트",
                  // 선택적 속성(기본값이 아닌 경우에만 포함):
                  "bullet": true,           // 명시적 글머리 기호 감지
                  "level": 0,               // bullet이 true일 때만 포함
                  "alignment": "CENTER",    // CENTER, RIGHT(LEFT 아님)
                  "space_before": 10.0,     // 포인트 단위 단락 앞 공간
                  "space_after": 6.0,       // 포인트 단위 단락 뒤 공간
                  "line_spacing": 22.4,     // 포인트 단위 줄 간격
                  "font_name": "Arial",     // 첫 번째 실행에서
                  "font_size": 14.0,        // 포인트 단위
                  "bold": true,
                  "italic": false,
                  "underline": false,
                  "color": "FF0000"         // RGB 색상
                }
              ]
            }
          }
        }
      ```

   * 주요 기능:
     - **슬라이드**: "slide-0", "slide-1" 등으로 명명
     - **모양**: 시각적 위치(위에서 아래로, 왼쪽에서 오른쪽으로)에 따라 "shape-0", "shape-1" 등으로 정렬
     - **자리 표시자 유형**: TITLE, CENTER_TITLE, SUBTITLE, BODY, OBJECT 또는 null
     - **기본 글꼴 크기**: 레이아웃 자리 표시자에서 추출된 포인트 단위 `default_font_size`(사용 가능한 경우)
     - **슬라이드 번호 필터링**: SLIDE_NUMBER 자리 표시자 유형이 있는 모양은 인벤토리에서 자동으로 제외됩니다
     - **글머리 기호**: `bullet: true`인 경우 `level`은 항상 포함됩니다(0인 경우에도)
     - **간격**: `space_before`, `space_after` 및 `line_spacing`(포인트 단위)(설정된 경우에만 포함)
     - **색상**: RGB의 경우 `color`(예: "FF0000"), 테마 색상의 경우 `theme_color`(예: "DARK_1")
     - **속성**: 기본값이 아닌 값만 출력에 포함됩니다

6. **대체 텍스트를 생성하고 데이터를 JSON 파일에 저장**
   이전 단계의 텍스트 인벤토리를 기반으로:
   - **중요**: 먼저 인벤토리에 존재하는 모양을 확인하십시오 - 실제로 존재하는 모양만 참조하십시오
   - **검증**: replace.py 스크립트는 대체 JSON의 모든 모양이 인벤토리에 존재하는지 검증합니다
     - 존재하지 않는 모양을 참조하면 사용 가능한 모양을 보여주는 오류가 발생합니다
     - 존재하지 않는 슬라이드를 참조하면 슬라이드가 존재하지 않음을 나타내는 오류가 발생합니다
     - 모든 검증 오류는 스크립트가 종료되기 전에 한 번에 표시됩니다
   - **중요**: replace.py 스크립트는 내부적으로 inventory.py를 사용하여 모든 텍스트 모양을 식별합니다
   - **자동 지우기**: 인벤토리의 모든 텍스트 모양은 "paragraphs"를 제공하지 않으면 지워집니다
   - 콘텐츠가 필요한 모양에 "paragraphs" 필드를 추가하십시오("replacement_paragraphs" 아님)
   - 대체 JSON에 "paragraphs"가 없는 모양은 자동으로 텍스트가 지워집니다
   - 글머리 기호가 있는 단락은 자동으로 왼쪽 정렬됩니다. `"bullet": true`일 때 `alignment` 속성을 설정하지 마십시오
   - 자리 표시자 텍스트에 적절한 대체 콘텐츠를 생성하십시오
   - 모양 크기를 사용하여 적절한 콘텐츠 길이를 결정하십시오
   - **중요**: 원래 인벤토리의 단락 속성을 포함하십시오 - 텍스트만 제공하지 마십시오
   - **중요**: bullet: true인 경우 텍스트에 글머리 기호 기호(•, -, *)를 포함하지 마십시오 - 자동으로 추가됩니다
   - **필수 서식 지정 규칙**:
     - 헤더/제목은 일반적으로 `"bold": true`를 가져야 합니다
     - 목록 항목은 `"bullet": true, "level": 0`을 가져야 합니다(bullet이 true일 때 level이 필요함)
     - 정렬 속성을 보존하십시오(예: 가운데 정렬된 텍스트의 경우 `"alignment": "CENTER"`)
     - 기본값과 다른 경우 글꼴 속성을 포함하십시오(예: `"font_size": 14.0`, `"font_name": "Lora"`)
     - 색상: RGB의 경우 `"color": "FF0000"` 또는 테마 색상의 경우 `"theme_color": "DARK_1"` 사용
     - 대체 스크립트는 **적절하게 서식이 지정된 단락**을 기대하며, 단순한 텍스트 문자열이 아닙니다
     - **겹치는 모양**: 더 큰 default_font_size 또는 더 적절한 placeholder_type을 가진 모양을 선호하십시오
   - 대체가 포함된 업데이트된 인벤토리를 `replacement-text.json`에 저장하십시오
   - **경고**: 다른 템플릿 레이아웃에는 다른 모양 개수가 있습니다 - 대체를 만들기 전에 항상 실제 인벤토리를 확인하십시오

   적절한 서식을 보여주는 paragraphs 필드 예:
   ```json
   "paragraphs": [
     {
       "text": "새 프레젠테이션 제목 텍스트",
       "alignment": "CENTER",
       "bold": true
     },
     {
       "text": "섹션 헤더",
       "bold": true
     },
     {
       "text": "글머리 기호 기호가 없는 첫 번째 글머리 기호",
       "bullet": true,
       "level": 0
     },
     {
       "text": "빨간색 텍스트",
       "color": "FF0000"
     },
     {
       "text": "테마 색상 텍스트",
       "theme_color": "DARK_1"
     },
     {
       "text": "특별한 서식 없는 일반 단락 텍스트"
     }
   ]
   ```

   **대체 JSON에 나열되지 않은 모양은 자동으로 지워집니다**:
   ```json
   {
     "slide-0": {
       "shape-0": {
         "paragraphs": [...] // 이 모양은 새 텍스트를 가져옵니다
       }
       // 인벤토리의 shape-1 및 shape-2는 자동으로 지워집니다
     }
   }
   ```

   **프레젠테이션의 일반적인 서식 패턴**:
   - 제목 슬라이드: 굵은 텍스트, 때때로 가운데 정렬
   - 슬라이드 내 섹션 헤더: 굵은 텍스트
   - 글머리 기호 목록: 각 항목은 `"bullet": true, "level": 0`이 필요합니다
   - 본문 텍스트: 일반적으로 특별한 속성이 필요하지 않습니다
   - 인용: 특별한 정렬 또는 글꼴 속성을 가질 수 있습니다

7. **`replace.py` 스크립트를 사용하여 대체 적용**
   ```bash
   python scripts/replace.py working.pptx replacement-text.json output.pptx
   ```

   스크립트는 다음을 수행합니다:
   - 먼저 inventory.py의 함수를 사용하여 모든 텍스트 모양의 인벤토리를 추출합니다
   - 대체 JSON의 모든 모양이 인벤토리에 존재하는지 검증합니다
   - 인벤토리에서 식별된 모든 모양에서 텍스트를 지웁니다
   - 대체 JSON에서 "paragraphs"가 정의된 모양에만 새 텍스트를 적용합니다
   - JSON의 단락 속성을 적용하여 서식을 보존합니다
   - 글머리 기호, 정렬, 글꼴 속성 및 색상을 자동으로 처리합니다
   - 업데이트된 프레젠테이션을 저장합니다

   검증 오류 예:
   ```
   오류: 대체 JSON의 잘못된 모양:
     - 'slide-0'에서 'shape-99' 모양을 찾을 수 없습니다. 사용 가능한 모양: shape-0, shape-1, shape-4
     - 인벤토리에서 'slide-999' 슬라이드를 찾을 수 없습니다
   ```

   ```
   오류: 대체 텍스트가 이러한 모양에서 오버플로를 악화시켰습니다:
     - slide-0/shape-2: 오버플로가 1.25" 악화됨(0.00"에서 1.25"로)
   ```

## 썸네일 그리드 만들기

빠른 분석 및 참조를 위해 PowerPoint 슬라이드의 시각적 썸네일 그리드를 만들려면:

```bash
python scripts/thumbnail.py template.pptx [output_prefix]
```

**기능**:
- 생성: `thumbnails.jpg`(또는 큰 덱의 경우 `thumbnails-1.jpg`, `thumbnails-2.jpg` 등)
- 기본값: 5열, 그리드당 최대 30개 슬라이드(5×6)
- 사용자 정의 접두사: `python scripts/thumbnail.py template.pptx my-grid`
  - 참고: 특정 디렉토리에 출력하려면 출력 접두사에 경로를 포함해야 합니다(예: `workspace/my-grid`)
- 열 조정: `--cols 4`(범위: 3-6, 그리드당 슬라이드에 영향)
- 그리드 제한: 3열 = 그리드당 12개 슬라이드, 4열 = 20, 5열 = 30, 6열 = 42
- 슬라이드는 0부터 시작합니다(슬라이드 0, 슬라이드 1 등)

**사용 사례**:
- 템플릿 분석: 슬라이드 레이아웃과 디자인 패턴을 빠르게 이해
- 콘텐츠 검토: 전체 프레젠테이션의 시각적 개요
- 탐색 참조: 시각적 모양으로 특정 슬라이드 찾기
- 품질 확인: 모든 슬라이드가 적절하게 서식이 지정되었는지 확인

**예**:
```bash
# 기본 사용
python scripts/thumbnail.py presentation.pptx

# 옵션 결합: 사용자 정의 이름, 열
python scripts/thumbnail.py template.pptx analysis --cols 4
```

## 슬라이드를 이미지로 변환

PowerPoint 슬라이드를 시각적으로 분석하려면 두 단계 프로세스를 사용하여 이미지로 변환하십시오:

1. **PPTX를 PDF로 변환**:
   ```bash
   soffice --headless --convert-to pdf template.pptx
   ```

2. **PDF 페이지를 JPEG 이미지로 변환**:
   ```bash
   pdftoppm -jpeg -r 150 template.pdf slide
   ```
   이렇게 하면 `slide-1.jpg`, `slide-2.jpg` 등과 같은 파일이 생성됩니다.

옵션:
- `-r 150`: 해상도를 150 DPI로 설정(품질/크기 균형을 위해 조정)
- `-jpeg`: JPEG 형식 출력(선호하는 경우 `-png` 사용)
- `-f N`: 변환할 첫 번째 페이지(예: `-f 2`는 2페이지부터 시작)
- `-l N`: 변환할 마지막 페이지(예: `-l 5`는 5페이지에서 중지)
- `slide`: 출력 파일의 접두사

특정 범위에 대한 예:
```bash
pdftoppm -jpeg -r 150 -f 2 -l 5 template.pdf slide  # 2-5페이지만 변환
```

## 종속성

필요한 종속성(이미 설치되어 있어야 함):

- **markitdown**: `pip install "markitdown[pptx]"` (프레젠테이션에서 텍스트 추출용)
- **pptxgenjs**: `npm install -g pptxgenjs` (html2pptx를 통해 프레젠테이션 생성용)
- **playwright**: `npm install -g playwright` (html2pptx에서 HTML 렌더링용)
- **react-icons**: `npm install -g react-icons react react-dom` (아이콘용)
- **sharp**: `npm install -g sharp` (SVG 래스터화 및 이미지 처리용)
- **LibreOffice**: `sudo apt-get install libreoffice` (PDF 변환용)
- **Poppler**: `sudo apt-get install poppler-utils` (PDF를 이미지로 변환하는 pdftoppm용)
- **defusedxml**: `pip install defusedxml` (안전한 XML 파싱용)
